# Device configurations for Galaxy J2 Prime (grandpplte)

The Galaxy J2 Prime (codenamed "grandpplte") is a low end smartphone from Samsung. It's released in November 2016.

## Device specifications
| Basic                   | Spec sheet                                        |
| -----------------------:|:--------------------------------------------------|
| CPU                     | Quad-core (4x1.44 GHz Cortex-A53)                 |
| Chipset                 | Mediatek MT6737T (28 nm)                          |
| GPU                     | Mali-T720                                         |
| Memory                  | 1.5 GB RAM                                        |
| Shipped Android Version | Android 6.0.1 (Marshmallow)                       |
| Storage                 | 8/16 GB eMMC                                      |
| Battery                 | Removable Li-Ion 2600 mAh battery                 |
| Display                 | 540 x 960 pixels, 16:9 ratio (~240 ppi density)   |
| Camera (Back)           | 8 MP                                              |
| Camera (Front)          | 5 MP                                              |
